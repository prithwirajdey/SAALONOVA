# Changelog

## Version 3.1, 2026

Current documented release of SAALONOVA.

### Major functionality

- Support for completely randomised design (CRD).
- Support for randomised block design (RBD/RCBD).
- Support for split-plot design.
- Support for strip-plot design.
- Support for split-split-plot design.
- Year-wise ANOVA.
- Bartlett-based homogeneity assessment across years.
- Fmax reporting.
- Pooled ANOVA across years.
- Standard error and critical difference calculations.
- LSD/CD, DMRT and Tukey HSD mean separation.
- Significance-letter groupings.
- SD and SE presentation options.
- Coefficient of variation reporting.
- Wide-grid data entry.
- Long-format CSV/TXT/TSV import.
- Long-format data export.
- Copyable result tables.
- `.xls` report export.
- Built-in examples for supported designs.
- Integrated software citation and contact information.
